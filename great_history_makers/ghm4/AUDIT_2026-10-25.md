## Gaps against the final direction
| Requirement | Gap | Plan |
|---|---|---|
| Subtle hand movement | Not available (only blink and cloth ripples) | Add a `sway` effect: soft region rotating a few degrees around a pivot (wrist, elbow, sword hilt) |
| Character consistency | Style reference only; no face reference | SDXL workflow with **two IP-Adapters**: style (whole approved image) + face (crop of the approved face, Plus-Face model, no InsightFace); LoRA later |
| Model choice | SDXL base only | Keep SDXL base as the default (fits 8 GB well); add an optional **FLUX.1 [schnell] GGUF** workflow (Apache-2.0) for an A/B on composition and hands |
| Automation | Plates, metadata and storyboard are hand-assembled per video | `ghm4/episode.py`: one episode spec → illustration job → ranked candidates → upscale job → plates + automatic metadata presets + matte → storyboard → narration timing → render → verify |
| Metadata cost | Eyes, flags, smoke, hints placed by hand (most expensive Claude step) | Presets per shot type + automatic flag (tricolour) and sky detection; only the eye outline stays manual, and only for close-ups |
| Windows setup | Manual guide only | PowerShell installer that downloads from the official sources and verifies SHA-256 hashes, plus the existing check script |
| First real test | Queued job `napoleon_test3_v1` never ran | Replaced by the three-scene test the client asked for (portrait, battlefield, map) |
